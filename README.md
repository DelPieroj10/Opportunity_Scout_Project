# Opportunity Scout

**Opportunity Scout** is a research workspace designed to help teams and founders discover market opportunities faster.

Instead of spending days manually reviewing competitor sites, customer reviews, pricing pages, and discussion forums, the system coordinates multiple research streams simultaneously. It delivers a structured summary of opportunities, risks, and recommendations for a given market category.

> 🚧 Project currently under active development, created as a technical exercise and portfolio piece.

## ✨ What does it analyze?

- 🏢 Competitors
- 💰 Pricing strategies
- 🗣️ Customer reviews *(estimated — see note below)*
- 📍 Brand positioning
- 📈 Market trends *(estimated — see note below)*
- ⚠️ Frequently reported issues

> **Note on Customer Reviews / Market Trends:** the [Foursquare Places API](https://location.foursquare.com/places/) doesn't expose review scores or historical trend data. Instead of leaving these sections empty, the app derives **heuristic signals** from the data it *does* have:
> - **Customer Reviews** → estimated from how many competitors have a public website (a common proxy for online reputation and discoverability).
> - **Market Trends** → estimated from category concentration and geographic clustering of the search results (a structural snapshot, not a time series).

## 🛠️ Tech Stack

This is a **pnpm workspace** with two packages: the frontend (root) and the backend (`opportunity-scout-backend/`).

| Category | Technology |
|---|---|
| Frontend framework | [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) |
| Backend framework | [Express](https://expressjs.com/) + TypeScript, running on [tsx](https://github.com/privatenumber/tsx) |
| External API | [Foursquare Places API](https://location.foursquare.com/places/) |
| Bundler / Dev server | [Vite](https://vite.dev/) |
| Charts | [Recharts](https://recharts.org/) *(lazy-loaded — see note below)* |
| Styling | [Tailwind CSS](https://tailwindcss.com/) |
| UI Components | [shadcn/ui](https://ui.shadcn.com/) built on [Base UI](https://base-ui.com/) primitives |
| Package Manager | [pnpm](https://pnpm.io/) |
| Icons | [lucide-react](https://lucide.dev/) |

> **Note on bundle size:** `Recharts` pulls in a sizable set of `d3-*` dependencies. Since charts are only needed after a search returns results, `MarketDistributionCharts` is loaded via `React.lazy()` + `Suspense`, keeping it out of the initial JS bundle.

### Note on shadcn/ui + Base UI

This project uses the shadcn/ui variant built on **Base UI** instead of Radix UI. The main difference to keep in mind when adding or modifying components:

- Radix UI uses the `asChild` (boolean) + `children` pattern.
- Base UI uses the `render` pattern (receives the full element as the prop value).

\`\`\`tsx
// Base UI pattern used in this project
<SidebarMenuButton
  render={
    <a href="/ruta">
      <span>Texto</span>
    </a>
  }
/>
\`\`\`

## 🚀 How to run the project

### Prerequisites

- Node.js 18+
- [pnpm](https://pnpm.io/installation)
- A [Foursquare Places API](https://location.foursquare.com/places/) key

### Installation

From the project root (installs both workspace packages):

\`\`\`bash
pnpm install
\`\`\`

### Environment variables

**Backend** — create `opportunity-scout-backend/.env` (see `.env.example` in that folder):

\`\`\`env
FOURSQUARE_API_KEY=your_foursquare_api_key
CLIENT_URL=http://localhost:5173
PORT=3001
\`\`\`

**Frontend** — create a `.env` file at the project root:

\`\`\`env
VITE_API_URL=http://localhost:3001
\`\`\`

### Development mode

Run each workspace in its own terminal:

\`\`\`bash
# Terminal 1 — backend (http://localhost:3001)
pnpm --filter opportunity-scout-backend dev

# Terminal 2 — frontend (http://localhost:5173)
pnpm dev
\`\`\`

### Production build

\`\`\`bash
# Frontend
pnpm build

# Backend
pnpm --filter opportunity-scout-backend build
pnpm --filter opportunity-scout-backend start
\`\`\`

### Add a new shadcn component

\`\`\`bash
pnpm dlx shadcn@latest add <component-name>
\`\`\`
